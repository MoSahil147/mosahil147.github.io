# Sahil Mohapatra: Portfolio

Personal portfolio website of **Sahil Mohapatra**, AI Engineer (LLM, RAG, Agentic AI) and Computer Science undergraduate at BITS Pilani, Dubai Campus.

🔗 **Live site:** [mosahil147.github.io](https://mosahil147.github.io)

## About

A single-page portfolio built with plain HTML, CSS and JavaScript, with no frameworks and no build step. It showcases projects, work experience, education, skills, certifications and hobbies, with a video hero section and smooth scroll navigation.

## Sections

- **About Me**: quick intro
- **Projects**: GitFlix, Scuba-Doo, Social Media Content Analysis, Healthcare AI Assistant (RAG), LLM Fine-Tuning with LoRA, Predictive Analysis of Social Media, Music Streaming Platform UI
- **Experience**: ODeX Global (Backend AI/ML Intern), Skolar EdTech (Full-Stack Web Dev Intern)
- **Education**: BITS Pilani, Dubai Campus
- **Skills**: languages, frameworks/tools and areas of expertise
- **Certifications**: courses and hackathon results
- **Hobbies**
- **Contact**: LinkedIn, email, GitHub, Instagram

## Tech Stack

## Running Locally

No build step required, just open the page in a browser:

```bash
git clone https://github.com/MoSahil147/mosahil147.github.io.git
cd mosahil147.github.io/main-code
open index.html   # or double-click the file
```
